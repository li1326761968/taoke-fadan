# 淘客全自动发单助手 v1.0

**适用场景：** 有二三十个 QQ 群发优惠券的淘客站长  
**技术栈：** Python 3.8+ / Tkinter（GUI） / 折淘客免费 API / NapCat QQ机器人框架  
**运行系统：** Windows 7/10/11（也可以跑在 Windows 服务器 2016/2019/2022 长期挂着）

---

## ✨ 功能一览

| 模块 | 功能 |
|------|------|
| 折淘客 API | 超高佣 / 9.9 包邮 / 全天销量榜 / 高评分 4 种来源 |
| 自动转链 | 调用折淘客高佣转链接口，生成带自己 PID 的淘口令+二合一链接 |
| 文案生成 | 4 种模板：标准 / 紧迫感 / 简洁 / 可爱风 |
| QQ 群发 | NapCat HTTP API，**文本+图片合并成一条消息**（降低拆条风控） |
| 多群同时 | 所有目标群用英文逗号 `,` 分隔，一次循环发到所有群 |
| 定时循环 | 翻页拉取，商品自动去重（不重复发同一商品） |
| 风控友好 | 随机 ±30 秒延时、最低 60 秒间隔保护 |
| 筛选规则 | 最低佣金 / 价格区间 / 最低销量 |
| 监听跟单 | 监听上家群消息 → 自动解析淘口令/链接/ID → 转链 → 转发到自己群 |
| 调试工具 | 一键测试折淘客、测试 NapCat、拉取 NapCat 群列表（方便复制群号） |

## 🚀 快速开始（Windows）

### 1️⃣ 安装 Python
- 下载 Python 3.8+：<https://www.python.org/downloads/windows/>
- **安装时必须勾选 ☑ Add Python to PATH**
- 打开 cmd 输入 `python --version`，能看到版本号即为成功

### 2️⃣ 注册折淘客并授权
1. 打开 <https://www.zhetaoke.com/> → 注册登录
2. **对接管理 → 应用管理**：拿到 `AppKey`
3. **授权管理 → 淘客授权管理**：绑定你的淘宝联盟账号，授权后生成 **SID**
4. 把你的淘宝联盟 **PID**（格式 `mm_xxx_xxx_xxx`）填到折淘客后台

### 3️⃣ 安装并登录 NapCat
- 下载：<https://github.com/NapNeko/NapCatQQ/releases>
- 解压后运行 `napcat.bat`（或对应版本启动脚本）
- 弹出二维码 → **用 QQ 小号扫码登录**（不要用主号！）
- 在 NapCat 配置里确认 **HTTP API 已开启，端口=3000**（默认就是）

### 4️⃣ 启动发单软件
1. **双击** `启动.bat`（首次运行会自动 `pip install requests`）
2. 打开后进入 **⚙️ 配置** 页：
   - 填 AppKey / SID / PID
   - NapCat 地址：`127.0.0.1`  端口：`3000`（和 NapCat 配置一致）
   - QQ 群号：所有群发群，英文逗号分隔（二三十个群全写上）
3. 依次点：**💾 保存配置** → **🔗 测试折淘客API** → **🤖 测试NapCat连接**
4. 两项测试都 ✅ 后，切到 **🚀 发单** 页 → **🚀 启动自动发单**
5. （可选）需要跟单就去 **👂 监听跟单** 页填好源/目标群号，启动即可

## ⚠️ 风控 & 防封建议（必须看）

1. **一定要用 QQ 小号** 登录 NapCat，封号风险自负。
2. 发单间隔建议 **≥ 300 秒（5 分钟）**，间隔太短会触发 QQ 群风控。
3. 勾选 **"随机±30秒延时"**，避免机械节奏。
4. NapCat 长期运行最好放在 **Windows 服务器** 或不关机的电脑上，不能睡眠休眠。
5. 单个群每小时 **1~2 条**是比较安全的节奏，有二三十个群可以 24 小时均匀铺。
6. 如果连续多条失败，先停 10~30 分钟再恢复；可能是群临时禁言/账号限流。

## ❓ 常见问题

**Q: SID 在哪看？**  
A: 折淘客 → 授权管理 → 淘客授权管理 → 授权列表中的 SID 字段。

**Q: PID 在哪看？**  
A: 淘宝联盟 → 推广管理 → 推广位管理 → 对应推广位的 PID。

**Q: 测试 NapCat 失败？**  
A: ① NapCat 没启动 ② 端口号不一致 ③ NapCat 设置了 Token 但软件没填 ④ 防火墙拦截。

**Q: 测试折淘客 API 成功，但淘口令打开是失效/不是我的 PID？**  
A: SID 或 PID 授权有问题，回折淘客重新授权一次，确保 SID 对应 PID 一致。

**Q: 发单日志显示"转链失败"？**  
A: 90% 原因是 SID 没填或授权过期。折淘客授权有时效，过期了重新授权一下。

**Q: 监听跟单没触发？**  
A: ① 源群号填错 ② 监听QQ号没写准确（留空=监听所有人，可先留空测试） ③ NapCat 拉历史消息接口被禁。
